# LandscapeAI

## Description
LandscapeAI is an innovative web application that uses advanced AI models to transform landscape images effortlessly. By integrating Hugging Face models for real-time image manipulation, the platform allows users to reimagine their photos with artistic precision. With a responsive React interface and an optimized Flask backend, users can upload, preview, and download high-quality transformations seamlessly. Scalable and user-friendly, LandscapeAI empowers creativity while delivering a smooth and intuitive experience.

## Tech Stack
- HuggingFace models (image generation / transformation)
- React
- FastAPI (Flask-style backend)
- TypeScript

# Jarvis

## Description
Jarvis is an AI-driven lead management and campaign tracking application that simplifies lead tracking, behavioural analysis, automated campaigns, and lead scoring. With integrated email/SMS communication, detailed lead insights, and scalable features, Jarvis enhances productivity, improves ROI, and enables data-driven decision-making for streamlined marketing strategies.

## Tech Stack
- OpenAI API
- Twilio (email + SMS)
- React
- FastAPI

## Target Market
- Businesses and individuals managing leads
- Salesforce-adjacent workflows

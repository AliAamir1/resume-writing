# PhotoMentor

## Description
Photomentor is an AI-powered application designed to support photographers in enhancing their skills and creativity. By offering personalized feedback on photos, suggesting improvements, and providing advanced tips tailored to skill levels, it empowers users to refine composition, lighting, and post-processing techniques. The platform also integrates AI-guided tutorials and real-time suggestions, making it an invaluable tool for photographers of all experience levels aiming to elevate their craft.

## Tech Stack
- OpenAI API (vision)
- FastAPI
- React
- TypeScript

## Target Market
- Photographers learning composition / lighting / post-processing
- All experience levels

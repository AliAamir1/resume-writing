# Convify

Drag-and-drop form builder with live preview, response review, and performance analytics for marketing teams.

## Bullets

- *Drag-and-Drop Builder*: Built a visual form builder on Craft.js with live preview so non-technical marketers create, customize, and publish forms without writing code.
- *Analytics Dashboard*: Shipped response review and form-performance monitoring with graphical reporting.
- *Full-Stack Development*: Built on Next.js with NextAuth authentication, Redux state, and Prisma over MySQL.
- *Containerized CI/CD*: Dockerized the application and automated build and deploy through GitHub Actions.

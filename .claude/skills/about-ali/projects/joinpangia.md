# joinpangia

Real-time news verification chatbot built on a LangChain agents architecture, extending to video analysis of on-camera statements. Formerly True AVI.

## Bullets

- *LangChain Agent Architecture*: Built a real-time news verification chatbot on a LangChain agents architecture that fact-checks claims against live data sources rather than a static training corpus.
- *Multi-Modal Analysis*: Extended verification to video, analyzing debate and informational footage to check statements made on camera.
- *Python Backend Development*: Built the service on FastAPI and Python with a Node.js layer, Firebase, and GCP hosting behind a SvelteKit frontend.

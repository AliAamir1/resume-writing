# Convify

## Description
Convify is an intuitive platform that makes form creation and monitoring a breeze. With its user-friendly drag-and-drop interface built on Next.js and Craft.js, you can easily create, customize, and manage forms without any hassle. It also offers features to review form responses and monitor performance through graphical representations. Plus, you can view changes in real-time with its convenient preview feature, allowing you to see updates on the go.

## Tech Stack
- Next.js
- NextAuth
- Docker
- GitHub Actions (CI/CD)
- Redux
- MySQL
- Prisma ORM
- Shadcn
- Craft.js (drag-and-drop builder)

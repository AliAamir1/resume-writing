# joinpangia (formerly True AI / True AVI)

## Description
joinpangia (previously known as True AVI) is an artificial verification intelligence chatbot to verify news using real-time data with the help of LangChain agents architecture. You can also analyze videos and verify the reality behind statements in those videos — debates, informational content, etc.

## Tech Stack
- LangChain (agents architecture)
- Python
- FastAPI
- Node.js
- Firebase
- GCP
- SvelteJS
- OpenAI

## Target Market
- Journalists
- Normal people looking to verify news

## Links
- Deployment: https://joinpangia.com/

## Notes
Real-time fact-checking. Multi-modal: text claims + video analysis. Agentic LangChain architecture is the core differentiator.

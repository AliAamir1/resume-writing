# Crypto Chart CLI Terminal

## Description
Crypto Chart CLI is a command-line interface (CLI) tool for fetching cryptocurrency prices, uploading CSV files to Firebase storage, deleting files from the database, and drawing charts based on the data in the CSV files.

## Tech Stack
- Next.js
- Firebase Storage
- Vercel
- Tailwind
- hookState

## Target Market
- Crypto market

## Links

## Notes
CLI-style web UI. Smaller demo project — useful as proof of unusual UX patterns (terminal-in-browser) rather than as a flagship.

# TSKR

## Description
Tskr is a freelancer marketplace focused on transparency and simplicity. It offers clients a user-friendly dashboard to create, manage, and monitor job postings, while freelancers enjoy a tailored dashboard to manage projects and contracts. The "All Jobs" feature allows freelancers to easily browse and apply for available projects across multiple categories.

# PerigonAi

## Description
The project seamlessly integrates MapBox and Scrollama, creating an immersive storytelling website that unfolds the vibrant life around newly constructed blocks in Saudi Arabia. Our project goes beyond storytelling, offering extensive visualized demographic insights. Users can easily grasp the proximity of schools, colleges, offices, and leisure spots to the blocks, fostering a deeper connection with the community on our react-built platform deployed on Amplify.

## Tech Stack
- React
- AWS Amplify
- AWS CodeCommit
- MapBox
- Scrollama (scroll-driven storytelling)
- Tailwind

## Target Market

# Organyz

## Description
Organyz is an AI-powered asset management solution designed to streamline digital organization. With a single click, Organyz intelligently organizes your folders and files into a clear, structured hierarchy. It automatically renames files, suggests logical folder structures, and generates concise, context-aware descriptions for your documents.

Leveraging advanced AI, Organyz detects duplicate and similar files, applies smart tags for easy categorization, and enables fast, semantic file retrieval. Whether managing personal archives or enterprise-level assets, Organyz ensures efficient, intuitive, and scalable digital organization.

## Tech Stack
- FastAPI
- LangGraph (agentic orchestration)
- AWS: Sagemaker, Bedrock, RDS
- HuggingFace
- OpenAI

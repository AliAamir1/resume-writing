# Organyz

AI asset management platform that organizes files into structured hierarchies, renames them, describes them, and makes them semantically retrievable.

## Bullets

- *Agentic AI Orchestration*: Built an AI asset management platform on LangGraph and FastAPI that organizes files into a structured hierarchy, renames them, and generates context-aware descriptions in a single action.
- *Semantic Search*: Implemented embedding-based file retrieval alongside duplicate and near-duplicate detection with automatic tagging for categorization.
- *AWS Machine Learning Services*: Ran inference across AWS SageMaker, AWS Bedrock, and HuggingFace models with RDS persistence.
- *Python Backend Development*: Built the service layer in FastAPI, scaling from personal archives to enterprise asset libraries.

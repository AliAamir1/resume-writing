# PerigonAi

Scroll-driven geo-storytelling site presenting demographic context around new residential developments in Saudi Arabia.

## Bullets

- *Interactive Data Storytelling*: Built a scroll-driven narrative experience combining MapBox and Scrollama to unfold the neighborhood context around newly constructed residential blocks.
- *Geospatial Visualization*: Visualized demographic insights including proximity of schools, colleges, offices, and leisure destinations to each development.
- *AWS Amplify Deployment*: Shipped the React and Tailwind frontend through AWS Amplify with CodeCommit source control.

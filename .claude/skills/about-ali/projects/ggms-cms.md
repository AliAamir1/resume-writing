# GGMS Listings CMS

Property listing and lead-generation CMS for real-estate agents, with interactive maps, drawing tools, and saved-property tracking.

## Bullets

- *Real Estate Listings Platform*: Built a property listing and lead-generation CMS letting agents publish interactive listings, save properties, and track engagement insights.
- *Maps Integration*: Integrated Google Maps with polygon drawing tools and property filters so agents define custom geographic search areas.
- *Legacy Stack Modernization*: Worked across PHP, WordPress, and vanilla JavaScript while containerizing deployment to AWS EC2 and ECR with Docker and GitHub Actions.

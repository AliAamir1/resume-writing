# Startir.AI

AI edtech platform generating structured courses from a topic, broken into modules and lessons with auto-generated quizzes and instant grading.

## Bullets

- *LLM Content Generation*: Built an edtech platform generating full structured courses decomposed into modules and lessons through prompted structured output at scale.
- *Automated Assessment*: Generated per-module and per-lesson quizzes with instant grading, adapting the learning path to each learner's measured performance.
- *Full-Stack Development*: Built the backend on FastAPI and MySQL with a Next.js and ShadCN frontend.

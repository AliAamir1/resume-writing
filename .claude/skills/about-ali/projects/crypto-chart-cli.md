# Crypto Chart CLI Terminal

Terminal-style web UI for fetching cryptocurrency prices, managing CSV uploads, and charting the uploaded data.

## Bullets

- *Terminal-Style Web Interface*: Built a browser command-line interface for fetching cryptocurrency prices, uploading and deleting CSV datasets in Firebase Storage, and rendering charts from that data.
- *Frontend Development*: Built on Next.js with Tailwind and hookState, deployed to Vercel.

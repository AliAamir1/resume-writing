# Freight Dashboard Prototype

Earlier iteration of the freight operations dashboard. Mock data, no auth, never deployed. Superseded by the production ops portal. Keep off resumes unless a posting specifically rewards form architecture depth.

## Bullets

- *Multi-Step Form Architecture*: Built a three-step job creation wizard composing seven nested Zod schemas into one fully typed form with field arrays for line items and reactive total and profit-margin computation.
- *Data Table Engineering*: Built a reusable TanStack Table primitive with toolbar, column visibility, search, sorting, and pagination.
- *Dashboard Development*: Built KPI cards and Recharts revenue and job-volume charts for a freight operations overview.
